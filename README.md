# nvim

🌙 Neovim configuration with lua.

![Imagem do vim](vim.png)

## Install

**Prerequisites**

- Neovim 0.10+

Steps:

1. Clone the project in your config folder, usually `~/.config/nvim`:

```bash
git clone https://github.com/nato-re/nvim ~/.config/nvim
```

2. Open Neovim. You should see lazy.nvim downloading and installing the plugins in the first run
